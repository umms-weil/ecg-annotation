Walkthrough Videos
==================

Adjudication-specific walkthrough videos will be added to this page as they
become available.

The written guide provides the current instructions. Existing annotation
videos may demonstrate shared waveform tools, but they do not describe the
complete adjudication workflow.

.. note::

   No adjudication videos are embedded on this page yet.

   Video demonstrations should match the application version being used.

Starting an Adjudication
-----------------------

The walkthrough will demonstrate:

- Selecting Adjudication at startup.
- Selecting the reviewer.
- Connecting to the assigned batch.
- Interpreting record statuses.
- Loading two completed annotation inputs.
- Choosing displayed waveform leads.

Written instructions:

- :ref:`adjudication-getting-started`
- :ref:`adjudication-review-workflow`

The walkthrough will demonstrate:

- Green agreement regions.
- Red disagreement regions.
- Gray missing-coverage regions.
- Resolved regions.
- Source waveform overlays.

Written instructions:

- :ref:`adjudication-comparison-agreement`

Editing Final Decisions
----------------------

The walkthrough will demonstrate:

- Selecting a final interval.
- Changing CPR and rhythm.
- Adding required explanations or optional comments.
- Applying a final label.
- Dragging boundaries.
- Adding a boundary by clicking the waveform.
- Removing a boundary and merging intervals.

Written instructions:

- :ref:`adjudication-editing-labels-boundaries`

The walkthrough will demonstrate:

Accessible Video Instructions
-----------------------------

When videos are added, each walkthrough should include:

- Captions for spoken instructions.
- A transcript or equivalent written procedure.
- A descriptive video title.
- Related documentation links.
- Application version or recording date.

Videos supplement the written instructions rather than replacing them.
